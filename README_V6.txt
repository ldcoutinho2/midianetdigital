MIDIANETDIGITAL V6 - PACOTES DE ENGAJAMENTO

Alterações desta versão:
- Home simplificada para 3 serviços: Engajamento, Curtidas e Visualizações.
- Engajamento abre as 4 variações: 30/70, 60/40, 100% Brasileiros e BR Premium Ativos.
- Novos preços dos combos de engajamento aplicados.
- Curtidas e Visualizações mantidos com os valores existentes.
- Checkout mantido com Pix automático e verificação de Instagram.
- Combos passam a registrar seguidores + bônus de curtidas/visualizações no mesmo pedido.
- Distribuição de curtidas/visualizações por publicação com divisão automática equilibrada e possibilidade de ajuste.
- Publicações podem ser escolhidas pelo perfil e links podem ser adicionados manualmente.
- Pedido do combo é enviado aos serviços SMM após confirmação do pagamento.
- Página pós-pagamento prepara mensagem completa para acompanhamento via WhatsApp.
- Dashboard e eventos existentes foram preservados.
- Meta Pixel não foi removido nem reestruturado; o fluxo existente foi preservado.

IMPORTANTE:
O backend usa os IDs SMM existentes para seguidores brasileiros, mundiais, orgânicos, curtidas brasileiras e visualizações. Os combos 30/70 e 60/40 são compostos automaticamente a partir dos serviços existentes (30/70 = 30% BR + 70% mundial; 60/40 = 60% BR + 40% mundial). O BR Premium usa o serviço de seguidores orgânicos já configurado.
