MIDIANET DIGITAL V6 — COMBO DE ENGAJAMENTO FINAL

Nesta versão:
- Combos de engajamento mostram seguidores + curtidas + visualizações no resumo do checkout.
- O order bump antigo de 500 curtidas fica oculto para combos e não controla mais as publicações.
- Para qualquer combo que contenha curtidas/visualizações, o checkout busca as publicações automaticamente após encontrar o perfil.
- O cliente seleciona as publicações, distribui os bônus e confirma.
- Link manual de publicação não é tratado como bump quando o serviço é combo.
- O backend COMBOS/COMBO_PRECOS e a geração de Pix permanecem no fluxo atual.
- Pixel/eventos não foram alterados nesta versão.
